# ERP 利润诊断：方法与下一步

此报告针对项目内置合成 ERP 数据，不代表真实企业经营结论。所有计算通过本服务会话 SQL 算子执行；用户界面只负责展示。当前利润是销售额减销售成本，尚非包含所有经营费用的净利润。

## 先对账，再归因

1. 确认利润、销售额、件数、标价、折扣、销售成本的字段口径。
2. 检查销售额是否等于数量×标价×(1−折扣)，利润是否等于销售额−销售成本。
3. 先呈现原始结果，再给出排除待核查整单的敏感性对照，不直接删数据。
4. 用利润桥拆出件数、商品组合、同品标价、折扣、单位成本、金额公式差额、利润账差。
5. 用时间尺度与业务范围交叉验证，最后确定核查对象。

## 采用的精确分解

Π = Q × Σ[s × (p × (1−d) − c)] + R + E。

以横线代表两期平均、Δ代表当期−基期，m=p(1−d)−c，M=Σsm：

- 销量：ΔQ × 平均M。
- 商品组合：平均Q × Σ(Δs × 平均m)。
- 标价：平均Q × Σ(平均s × Δp × (1−平均d))。
- 折扣：−平均Q × Σ(平均s × 平均p × Δd)。
- 单位成本：−平均Q × Σ(平均s × Δc)。
- 金额差额与账差：分别为 ΔR、ΔE。

上述各项之和等于实际利润差额。交互项按预先声明的层级中点分摊；更换分摊口径可能改变各项份额，因此不应将其称为唯一的因果贡献。

## 本次应核查什么

- 金额口径：SO00211（2024-05-06）、SO00674（2024-03-24）、SO00123 与 SO00445（2024-10-22）。先查原始订单/发票、数量和金额是否同口径，以及税费返利是否单列。
- West / Technology：核对2025年折扣审批、促销时间、客户/渠道变化；销量增加但折扣侵蚀毛利。合成数据生成器确实在该组合注入了额外折扣，但真实业务需要凭证和政策记录验证。
- South：分别调查销量减少和商品组合迁移。异常基数解释部分下降，不代表剩余经营问题已经消失。

## 时间分析怎么用

日粒度找订单冲击；周粒度看节奏；月粒度观察连续变化并比较去年同月；季度减少短期波动；年度判断整体。每种尺度都查看总量与单位指标，不能仅凭某条更平滑的线认定趋势。

报告提供原始与排除待核查订单的利润双线、同比/环比数值。均价、单位成本和利润率由期间汇总重算。只有两年样本，不足以确认稳定季节性；边界周及闰日比较需要单独解释。

## 可继续开展的成熟业务方法

| 方法 | 业务用途 | 数据与验证条件 |
|---|---|---|
| 量价组合 / 利润桥 | 解释利润差额 | 已实现；保留分解口径与对账 |
| Pareto / ABC | 优先处理关键商品、客户、渠道 | 负向贡献与正向抵消分列；不要把负数直接混入普通累计占比 |
| Cohort / 留存与复购 | 区分获客质量与老客流失 | 首购月、去重订单、同龄观察窗口；未在此报告自动执行 |
| 本量利 / 盈亏平衡 | 判断销量目标与安全边际 | 需要固定费用和可变成本拆分 |
| 预算差异 / 弹性预算 | 区分业务量偏差与执行效率 | 需要预算量、价、成本和一致口径 |
| 时间序列分解与预测 | 趋势/季节性识别、未来区间 | 充足历史，滚动回测，对比季节朴素基线，不只看拟合优度 |
| 实验 / 准实验 | 检验政策的因果影响 | 可信对照与政策时点，验证适用假设，不能由相关性直接推出 |

参考：[Forecasting: Principles and Practice](https://otexts.com/fpp3/)；[NIST 异常值识别与处理](https://itl.nist.gov/div898/handbook/eda/section3/eda35h.htm)。
